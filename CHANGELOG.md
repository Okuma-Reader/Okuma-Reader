# Changelog

All notable changes to this project will be documented in this file.

## [0.0.3] - 2026-09-06

### Bug Fixes

- Keyboard shortcuts popup was sized and positionned incorrectly on Chromium
- Trigger npm publish on tag push

### Miscellaneous

- Add pre-commit hook and release prep script to simplify the developper experience

## [0.0.2] - 2026-09-06

### Bug Fixes

- Astro current page script wasn't working

### Miscellaneous

- Keep package-lock in sync
- Add release CI with OIDC publish and git-cliff
- Add original lossless format image textures
- Add necessary meta and licences for publishing

## [0.0.1] - 2026-09-06

### Bug Fixes

- Initial page value is displayed while the pdf loads
- Handle PDF source destruction gracefully in book reader and source
- No default for filename

### Features

- Host should handle the background, not the shell
- Implement abort signal handling in book reader and chapter scrubber
- Shared shell code in shared shell package
- Add react package
- Better props on the astro component
- Component auto mount for easier DX

### Miscellaneous

- More uniform demos
- Stop casting astro props
- Improved demo app
- Oxfmt setup
- Oxlint setup
